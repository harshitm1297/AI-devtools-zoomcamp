# Security evidence

This directory contains deterministic, sanitized security evidence suitable for source control.

- `threat-model.md` defines assets, trust boundaries, threats, and mitigations.
- `pr-audit.md` records the pre-publication review of the current implementation.
- `bandit-report.json` and `pip-audit-report.json` are generated by the named open-source tools;
  `requirements-audit.txt` is the exact runtime dependency export audited by pip-audit.

Regenerate the reports with the commands documented in `docs/testing.md`. CI additionally runs
Trivy against the repository and fails on high or critical vulnerability, secret, or
misconfiguration findings. Reports must never contain credentials or receipt data.
