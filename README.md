# Sprintlane

Sprintlane is an invite-only Kanban board for a project manager and their team.
It is being built for Homework 2 of the AI Dev Tools Zoomcamp.

## Current status

The product specification and project instructions are in place. The frontend,
OpenAPI contract, FastAPI backend, SQLite persistence, and tests will be added
in the next implementation stages.

## Documentation

- [_docs/specs.md](_docs/specs.md) — product specification and scope
- [AGENTS.md](AGENTS.md) — instructions for coding agents working in this repo
